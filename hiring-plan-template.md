# Hiring plan template

What you write up after the intake meeting. One page, sent to the hiring manager within 24 hours, so they can correct it before the search starts. The intake questions give you the inputs. This turns them into a plan both of you sign off on.

## 1. The role in one paragraph

Why this seat exists, what the person owns in their first ninety days, and what the team loses if it stays empty. Use the hiring manager's words, not the posting's.

## 2. What good looks like

| | Must have | Trade-off (flex if needed) | Not wanted |
| --- | --- | --- | --- |
| Skills | | | |
| Experience | | | |
| Background | | | |

Two real profiles the manager reacted to: one clear yes, one borderline, and what made the difference.

## 3. Constraints

- **Location:** fixed, flexible, or remote, and which time zones.
- **Compensation:** posted band, approved ceiling above it, and how the package is described (base, variable, sign-on, equity).
- **Process:** who interviews, in what order, assessing what.
- **Dependencies:** headcount approvals, internal candidates, anything that could pause the search.

## 6. Timeline

| Week | Milestone |
| --- | --- |
| 1 | Search live, first outreach out, first profiles in front of the manager |
| 2 | First screens, calibration check against the manager's feedback |
| 3 to 4 | Hiring manager interviews |
| 5 to 6 | Final rounds |
| 7 | Offer and close |

Adjust to the real process. The point is that the manager sees the dates their own feedback speed creates.

## 7. Risks and what you will do about each

| Risk | Early signal | Response |
| --- | --- | --- |
| Pay band too low for the market | Screens decline on comp | Bring market data and ask for the ceiling |
| Slow feedback | A profile sits past 48 hours | Escalate once, then reset the cadence |
| Requirements too narrow | Pipeline stalls below target | Revisit the trade-off list |
| Candidate drop-off | Silence between stages | Weekly touchpoint, named next step |

## 8. Cadence

A weekly 20-minute check-in with the same agenda: pipeline numbers against target, feedback outstanding, one decision needed from the manager. A shared tracker the manager can open without asking you.

## 9. What I need from you

Four commitments, copied from the intake: 48 hour feedback, standing interview slots, the panel named, and the approval ceiling in writing.
